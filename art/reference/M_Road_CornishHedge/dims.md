# M_Road_CornishHedge
Reference: Cornish hedge, stone-faced earth bank.
- Height 1.2 to 1.8 m (conservation handbook); traditional about 1.5 m (Western Morning News).
- Base width about equal to height; top about half base width (HER definition).
- Concave batter on faces (verify).

- https://conservationhandbooks.com/?p=601
